# كِتابي | Kitabi

> منصة جزائرية بسيطة وموثوقة لبيع، شراء، تبادل والتبرع بالكتب المدرسية والمراجع.

**كِتابي** هو سوق مجتمعي موجّه للعائلات والطلبة في الجزائر. يساعد المستخدم على العثور على الكتب حسب الطور الدراسي، المادة، الولاية ونوع الصفقة، مع تجربة عربية RTL ودعم فرنسي، وإمكانية التبادل والتبرع بالكتب مجانًا.

## المزايا الرئيسية

| المجال | ما توفره المنصة |
| --- | --- |
| البحث والاكتشاف | بحث سريع، تصفية متقدمة، ترتيب النتائج، وسجل عمليات البحث المحفوظ محليًا |
| العرض والشراء | إعلانات بيع، تبادل، وتبرع مع تفاصيل الحالة والسعر والولاية |
| التفاعل | المفضلة، تفاصيل الكتاب، المحادثة، التبليغ، واقتراح التبادل |
| التجربة المحلية | بيانات الأطوار والولايات الجزائرية، دعم RTL، وخيار العربية/الفرنسية |
| الخصوصية | نموذج أولي يعمل محليًا عبر `localStorage` دون خادم أو قاعدة بيانات |

## التقنية

المشروع تطبيق واجهة أمامية مبني باستخدام **React 19** و**TypeScript** و**Vite** و**Tailwind CSS 4**، مع أيقونات `lucide-react` وحركات خفيفة عبر `motion`.

## التشغيل محليًا

يتطلب المشروع Node.js 20 أو أحدث.

```bash
npm install
npm run dev
```

ثم افتح [http://localhost:3000](http://localhost:3000).

## أوامر الجودة والبناء

```bash
npm run lint    # فحص TypeScript
npm run build   # بناء نسخة الإنتاج
npm run preview # معاينة نسخة الإنتاج محليًا
```

## بنية المشروع

```text
src/
├── components/        # مكونات الواجهة والنوافذ المنبثقة
├── data/              # بيانات الأطوار والولايات والعينات الأولية
├── services/          # التخزين المحلي ومنطق البحث
├── types/             # الأنواع المشتركة في TypeScript
├── App.tsx            # الحالة العامة والتنقل بين واجهات التطبيق
├── index.css          # الهوية البصرية والأنماط العامة
└── main.tsx           # نقطة دخول React
```

## النشر على Vercel

المشروع مهيأ كتطبيق Vite أحادي الصفحة. إعدادات Vercel المقترحة هي:

| الإعداد | القيمة |
| --- | --- |
| Framework Preset | Vite |
| Build Command | `npm run build` |
| Output Directory | `dist` |
| Install Command | `npm install` |
| Node.js | 20.x أو أحدث |

يوفر ملف `vercel.json` إعادة توجيه لمسارات التطبيق إلى `index.html` حتى يعمل التنقل في الواجهة بعد التحديث المباشر للصفحة.

## ملاحظات المنتج

هذه النسخة تجريبية أمامية، لذلك تحفظ البيانات داخل متصفح المستخدم فقط. قبل إطلاق نسخة إنتاجية متعددة المستخدمين، يُنصح بإضافة نظام مصادقة، قاعدة بيانات، رفع صور آمن، ونظام إشعارات ومراجعة للإعلانات.

## المساهمة

للمساهمة، أنشئ فرعًا مستقلًا، نفّذ التغييرات، شغّل `npm run lint` و`npm run build`، ثم افتح Pull Request يشرح المشكلة والحل.

## الترخيص

يُرجى إضافة الترخيص القانوني المناسب قبل فتح المشروع أمام مساهمين خارجيين أو استخدامه تجاريًا.
